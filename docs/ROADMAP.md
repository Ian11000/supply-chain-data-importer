# Roadmap - supply-chain-data-importer

## Phase 1: Oracle Support
- SQL*Loader control file generation
- External table compatible flat files
- Basic validation rules

## Phase 2: Dynamics 365 / CRM
- CRM import template generation
- Lookup resolution for related entities
- Multi-entity import support

## Phase 3: Advanced Features
- Complex business rule validation
- Detailed error and rejection reporting
- Transformation rule engine

## Phase 4: Enterprise Features
- Multi-system output
- Full audit trail
- Performance optimization for large datasets
